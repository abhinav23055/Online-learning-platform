##  Overview

This project serves as a personal initiative to help beginners dive into web development using video tutorials and quizzes, without needing to install any software. The platform currently covers essential topics like **HTML**, **CSS**, and **JavaScript**, each explained through embedded YouTube videos followed by an interactive quiz to test the learner’s understanding.

Everything runs client-side, making it accessible and easy to deploy using GitHub Pages. Whether you're a self-learner or looking to revise basics, this platform is perfect for a quick and structured learning experience.

---

##  Features

-  **Video Lessons**  
  Each lesson includes an embedded YouTube video that explains a specific topic clearly and visually. These videos serve as the primary teaching content.

-  **Interactive Quizzes**  
  After watching each video, users can attempt a multiple-choice quiz to test what they’ve learned. Quizzes give immediate feedback upon submission.

-  **Client-Side Validation**  
  All logic for checking answers and calculating scores is handled with JavaScript in the browser. This keeps the experience smooth and fast.

-  **Simple and Clean Design**  
  The site is styled with CSS to ensure readability and visual consistency across all lessons.

-  **Responsive Layout**  
  The design adapts to different screen sizes, including desktops, tablets, and smartphones.

-  **Static Hosting**  
  Since the site uses only HTML, CSS, and JavaScript, it is hosted via GitHub Pages for free and does not require a backend server.

##  Pages Included

### `dashboard.html`
This is the homepage of the platform. It acts as the main dashboard, giving users access to different lessons. It features a card-like layout linking to the individual lesson pages.

### `lesson2.html` (CSS Basics)
This page teaches the fundamentals of CSS. It contains a video explaining how CSS works and a quiz to reinforce concepts like selectors, properties, and syntax.

### `lesson3.html` (JavaScript Basics)
This lesson covers the basics of JavaScript, including variables, data types, and functions. It also includes a quiz with immediate feedback.

### `style.css`
This file controls the appearance of all pages. It defines font styles, colors, spacing, button designs, and layout responsiveness.

### `script1.js`
This JavaScript file is responsible for handling quiz logic. It processes the user's answers, compares them with the correct ones, and displays a score instantly on the page.
